# Иске имля

Татарча белүчеләр өчен иске татар язуын өйрәнү курсының эчтәлеге һәм булачак PWA кушымтасының таләпләре.

Сейчас в репозитории готовятся учебная программа, теория, проверяемые задания, словарь, материалы для чтения и документация для реализации. Код приложения не разрабатывается.

Основной источник: Әхмәд хәзрәт Сабыр / А. Р. Сабиров, «Иске татар имлясы буенча дәреслек», третье издание, «Иман», Казань, 2020, 88 с.
