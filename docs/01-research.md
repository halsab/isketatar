## Аудитория и язык

Основное обещание: **«Татарча белүчеләр өчен иске имля»**. Курс рассчитан на понимание современного татарского, независимо от того, родной он для ученика или изученный. Интерфейс, теория, подсказки, вопросы и определения слов — татарские. Для объяснений используется современная кириллица; арабская графика является предметом обучения.

Два входа имеют общее продолжение:

1. **«Гарәп хәрефләрен беләм»** — короткая диагностика, затем татарские дополнительные буквы, гласные, гармония, особенности иске имля. Арабское чтение не освобождает от татарской орфографии.
2. **«Гарәп хәрефләрен өйрәнәм»** — направление письма, точки, формы, соединение, первые знакомые слова; затем тот же основной курс.

Русскоязычный человек, уже достаточно знающий татарский, использует общий курс. Обучение татарскому с нуля требует самостоятельной языковой программы, озвучивания, словарного минимума и иной последовательности. Смешивание этих задач сделает первые уроки слишком медленными для основной аудитории и слишком трудными для начинающих в языке. Перевод интерфейса сам по себе эту проблему не решает.

## Практические решения

- Урок строится как короткое объяснение → разобранные примеры → самостоятельное чтение → обратная связь → новый пример для проверки переноса.
- Подсказки выдаются ступенчато: обратить внимание на знак → показать правило → раскрыть чтение → раскрыть значение. Использованная помощь учитывается при оценке самостоятельности.
- Первые слова должны быть знакомы татароязычному человеку. Редкая арабо-персидская лексика не используется для проверки одной только способности различать буквы.
- Уже знающему арабское письмо объясняются именно расхождения: функция гласных букв, пропущенные гласные, гармония, написания аффиксов и татарское чтение заимствований.
- Словарь открывается из текста и различает исходное написание, чтение и значение. Прозрачное современное слово может требовать подсказки по графике, но не урока лексики.
- Обводка и письмо от руки полезны как дополнительная практика. Автоматическая оценка почерка не нужна для первого полноценного курса чтения.
- Исторические профили подписываются. Разные корректные написания не превращаются в неверные ответы из-за скрытой смены системы.
- Главный показатель результата — чтение ранее не разобранной строки с понятным уровнем помощи. Серия посещений и количество нажатий лишь вспомогательные показатели.

План PWA совместим с уроками, локальным словарём, локальной проверкой и сохранением прогресса на устройстве. GitHub Pages предоставляет статический хостинг; офлайн-работа требует явно подготовленного кэша и правил обновления. Эти решения раскрываются в контракте приложения.
