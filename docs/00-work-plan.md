# План подготовки учебного комплекта

## Цель и границы

Подготовить достаточный для реализации полноценного татароязычного PWA комплект: содержание курса по всей книге, правила и примеры, задания с ключами и объяснениями, словарь, практику чтения, тексты интерфейса, контракты данных и критерии приёмки. Разработка самого приложения в этот этап не входит.

Основной ученик знает татарский и может читать арабскую графику, но не знает иске имля. Второй маршрут предназначен для знающего татарский новичка в арабской графике. Обучение татарскому языку с нуля не входит в программу. Оба маршрута должны приводить к одной системе правил татарского письма.

## Этапы и отдельные коммиты

| Этап | Результат | Проверка перед коммитом |
|---|---|---|
| 0. План | Границы продукта, план материалов, критерии готовности | Все требования пользователя отражены; приложения нет |
| 1. Источник и редакционная политика | Снимок извлечённого текста, библиография, карта всех разделов, реестр ошибок и решений, профиль орфографии | Сверка с исходным DOC/DOCX, контрольная сумма, каждый раздел имеет назначение |
| 2. Программа и правила | Два входа, модули, полный каталог уроков и навыков, зависимости, реестр правил | Все содержательные разделы книги сопоставлены урокам/справочнику; исключения сохранены |
| 3. Теория и примеры | Полные татарские тексты каждого урока, объяснения, исходные и учебные примеры, справочные карточки | Есть объяснение, цель, примеры, результат; нет неподтверждённых строгих правил |
| 4. Практика и оценивание | Банк конкретных заданий, варианты, правильные ответы, татарские объяснения, входная диагностика и итоговые проверки | Ответы сверены с источником; проверяется новый материал; контекст снимает неоднозначность |
| 5. Словарь | Полный разбор §5.5–5.6, активный учебный словарь из уроков, варианты, источники, политика поиска | Слова и значения не перепутаны при извлечении таблиц; непроверенные формы выделены |
| 6. Чтение и материалы | Упорядоченные тексты, построчные разборы, задания, ключи, реестр визуальных и аудиоматериалов | Каждому тексту назначены навыки и помощь; происхождение текста явно указано |
| 7. Контракт приложения | Структура разделов, татарские строки интерфейса, форматы данных, правила проверки, прогресс, повторение, RTL, офлайн | Можно реализовать без самостоятельного изобретения методики и ключей |
| 8. Сквозная редактура | Проверка полноты, ссылок, ключей, письменности, языковой согласованности, итоговый комплект | Каждый критерий ниже подтверждён конкретными файлами; существенные дефекты устранены |

Коммиты выполняются после завершения и проверки этапа; после коммита работа продолжается. Публикация и push не входят в задачу. Если параллельно готовятся независимые материалы, они попадают только в соответствующий этап, а не случайно в соседний коммит.

## Какие материалы необходимы

1. **Источники:** сохранённое извлечение книги, устойчивые адреса разделов/строк, описание ограничений конвертации и внешние подтверждения спорных мест.
2. **Орфографическая политика:** основной учебный профиль, отличие от кадими и яңа имля, формы Unicode, диакритика, варианты, границы нормализации.
3. **Курс:** вводная диагностика; мост от арабского чтения к татарскому; входной модуль по графике; гласные; согласные; общие правила; аффиксы; заимствования; имена; исторические варианты и чтение.
4. **Каждый урок:** татарское название, цель, предварительные знания, полный текст объяснения, примеры, новые слова, ссылки на правила, упражнения, ожидаемый результат.
5. **Каждое проверяемое задание:** условие на татарском, стимул, тип ответа, допустимые ответы, объяснение, правило, источник, сложность и политика подсказки. Для выбора — конкретные отвлекающие варианты, для открытого ответа — конкретные ключи.
6. **Словарь:** историческое написание, чтение (если подтверждено), современное татарское значение, варианты, словоформы/аффиксы при необходимости, источник, статус достоверности.
7. **Чтение:** учебные строки и фрагменты из книги, уровни помощи, словарные связи, чтение кириллицей, вопросы и ответы. Составленные учебные предложения нельзя выдавать за исторический документ.
8. **Справочник:** буквы и соединение, гласные, гармония, аффиксы, заимствования, термины, сравнение исторических профилей.
9. **Интерфейс:** татарская навигация, инструкции, обратная связь, сообщения прогресса и офлайн-режима.
10. **Медиа:** перечень обязательных и дополнительных материалов; для аудио — сценарии, чтение, требования к записи; для иллюстраций — точное назначение. Основной курс должен быть пригоден к реализации без отсутствующих обязательных записей.
11. **Данные и приёмка:** устойчивые идентификаторы, связи урок–правило–слово–задание–текст, минимальный контракт хранения, проверки редакционного качества.

## Критерии завершения всей задачи

- [ ] Каждая глава, подраздел и приложение книги учтены; выбранная глубина объяснена.
- [ ] Правила привязаны к источнику и выбранному историческому профилю.
- [ ] Есть готовая теория на татарском для всех уроков обоих маршрутов, а не только заголовки или тезисы.
- [ ] Каждый учебный навык имеет конкретные задания и ключи; ошибки сопровождаются татарским объяснением.
- [ ] Есть отдельная проверка переноса навыка на новые слова/строки и итоговая проверка.
- [ ] Все записи §5.5–5.6 перенесены в контролируемый словарный корпус; спорные чтения не выдуманы.
- [ ] Активные слова курса связаны с проверенными написаниями и объяснениями.
- [ ] Материалы чтения содержат происхождение, чтение, помощь и ответы.
- [ ] Интерфейсные тексты и методические сообщения полностью татарские.
- [ ] Контракты данных и поведение проверки, повторения, словаря и чтения определены.
- [ ] Подготовлены сценарии медиа; обязательные зависимости от несозданных материалов отсутствуют.
- [ ] Проведена сквозная проверка покрытия, ссылок, ключей и Unicode; записаны результаты и реальные ограничения.
- [ ] После каждого завершённого этапа есть отдельный коммит; в репозитории нет реализации приложения.

## Редакционный принцип

Ошибки источника не превращаются в правила. Для спорного места фиксируются исходная формулировка, причина сомнения, принятое решение и допустимое использование. Исторический вариант может быть предметом узнавания, но не основанием объявлять другие варианты ошибкой. Статус «сверено с книгой» не означает независимой научной экспертизы.
