# Решения по проблемным местам книги

Эти решения определяют подготовку активных уроков. Полные наблюдения и исходные примеры находятся в `sources/audits/`. В словарном корпусе решения дополнительно фиксируются для каждой записи. «Исключить» означает сохранить в источниковом архиве и не использовать как правильный/неправильный эталон в приложении.

| ID | Место | Решение для курса |
|---|---|---|
| ED01 | §1.1, рассказ о 631 годе | Только как предание, приписанное источнику; не оцениваемый исторический факт. |
| ED02 | §1.3–1.4, четыре периода и числа букв | Авторская учебная схема; сравнение признаков, без требования единственного числа букв для всей истории. |
| ED03 | §1.3.4, 1930/1940 | В современной исторической справке использовать 1927/1939 со ссылкой на TATARICA; даты книги сохранены только в источнике. |
| ED04 | §2.4.2.1, آذَن / خَافِظ / ظَارِف | Исключить эти пары из активных эталонов; правило раскрыть на надёжных хәдис/Госман/Риза и иных подписанных примерах. |
| ED05 | §2.4.2.2, ل گوزه | Повреждённый пример не нужен для введения گ: использовать другие слова. |

| ED08 | §2.6.2.2, пробелы һә-рәсмия | Адресная подготовка display_form с сохранением одной лексемы; source_form остаётся неизменной. |
| ED09 | §2.6.5.1, таблица слитного произношения | Правило сохранения начала слова объяснить; повреждённые пары не использовать для ключей до отдельной сверки. Для курса достаточно словесного правила и однозначных примеров границ слов. |
| ED10 | §2.6.5.3, разорванное селкеде | Для примера использовать целую форму из §2.6.5.4, а не восстанавливать испорченную строку. |
| ED11 | §2.6.7.1, уч/үч/оч/өч/эч | Хранить пять отдельных пар, восстановленных по явно описанным правилам начала у/ү/о/ө/э; порядок RTL-списка не считать порядком соответствий. |
| ED12 | §2.6.7 и приложение 5, конечное о/ө | Основной курс показывает обычные позиции из словесного правила; таблица не доказывает продуктивность конечного о/ө. Географические исключения не превращать в общий алгоритм. |
| ED13 | §2.6.8, آلدئلار в J6 | Не использовать как чистый пример J6. Брать ясные пары كشىُ / كشيُلر и другие согласованные образцы. |
| ED14 | §2.6.8, сравнение короткого яй с уау | Объяснить ы/е непосредственно, без повторения вероятной оговорки. |
| ED15 | §2.7.4, общий заголовок «Х» | Разделить татарские х, һ и гласное ә; خ/ح/ه не объявлять взаимозаменяемыми. |
| ED16 | §2.7.7, زَهَر и зөбәрҗәд | Не использовать вторую подпись; не объединять разные слова по повреждённой записи. |
| ED17 | Приложения 1–4, формы ج/پ/چ и дополнительные точки | Учебная таблица строится из проверенных базовых букв и их форм; ошибочные глифы не являются «историческими вариантами». |
| ED18 | Приложение 5, «10 сузык» и й | Объяснять способы записи/функции; не делать из числа графических обозначений число гласных фонем. |
| ED19 | Примечание, тез/төз и русские подписи | Исправить смысл: тез — аякның бөгелә торган буыны; төз — туры, кыек түгел. Русские перевёрнутые значения не показывать. |

| ED22 | §3.7.2, Урманнан — اورامدن | Исключить повреждённую пару; использовать Казаннан/атамнан/көннән, где правило показано однозначно. |
| ED23 | §3.7.3, умбиш/чөңки/миң кайтам | Фонетические иллюстрации помечать отдельно; обычный кириллический ключ сохраняет унбиш/чөнки/мин кайтам. |
| ED24 | §4.3.2, ب назван уау | В объяснении исправить на و; все примеры данного раздела подтверждают و перед ب. Не считать букву ب вариантом уау. |
| ED25 | §4.3.4, «исемнәргә кушылмыйлар» | Не передавать как запрет -сыз/-сез при существительных. Подчеркнуть слитность суффикса и раздельность юк/түгел; оговорку об именах сверять с §4.1.2. |
| ED26 | §4.4, повторный номер 4.3.1 | Сохранять исходный номер в ссылке; устойчивый адрес S-080 и название снимают неоднозначность. |
| ED27 | §5.1, разновременные русские заимствования | Не представлять весь список как дореволюционный. Учить заданным адаптированным формам, а не генерации любого русского слова. |
| ED28 | §5.2, повреждённые пары мәгърифәт/хәсрәт | Не использовать как эталон противопоставления профилей. Надёжные пары китап/каләм достаточны для правила. |

| ED32 | §5.3.4, краткая схема һәмзә | Объяснить позиции и носители в проверенных словах. Не выдавать неполную схему за общий алгоритм орфографии арабского языка. |
| ED33 | §5.3.5, وو/يي | Различать два согласных и комбинацию гласной/согласной; не применять правило шадды к любому повтору кода. |

## Граница готовности

Реестр закрывает методические решения для разработки курса. Архивное исключение единичной ошибочной формы не исключает соответствующее правило: оно объясняется на других примерах. Все содержательные разделы сохраняются в карте покрытия. Если исправленная форма впоследствии вводится в активный материал, она получает собственное основание, а не теряет пометку о редакции.
