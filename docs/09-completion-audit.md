# Итоговая проверка учебного комплекта

Дата: 11 сентября 2026 года. Версия содержания: `2026.09.11.1`.

Подготовлены учебные материалы и требования для реализации татароязычного PWA по предоставленному учебнику. Код сайта, service worker, компоненты интерфейса и сервер не разрабатывались. Python-инструменты в `tools/` обслуживают проверку и индексацию содержания.

## Проверка содержания

Все основные блоки прошли повторное чтение независимо от их подготовки. Проверялись конкретные формулировки, ключи, морфемные разборы, ограничения правил, отличие современного татарского соответствия от исторической записи и доступность заданий на выбранном этапе.

Адресно исправлены, в частности:

- количество ә в әтәч: два;
- систематическое смещение93ссылок глав3–4, вызванное счётом U+2028 как новой строки;
- разграничение غ — гыйн и ع — гайн; название ڭ согласовано с книжным «саңгырау кәф»;
- современное слитное унбиш при сохранении раздельного источникового написания;
- «имена людей с Аллаһ» вместо ошибочного «названия книг»;
- правильный разбор кулыма: кул-ым-а;
- уточнение начальной һәмзә на әлифе в вопросе об ай хәрефләре;
- вопрос на изафет, который раньше содержал собственный ответ; добавлен допустимый кириллический вариант;
- ссылки морфемных вопросов на действительно относящиеся к ним правила;
- практика, преждевременно раскрывавшая один контрольный пример;
- отдельные примеры и задания для калын ده, корневого دان, краткого در и суффиксального ت;
- две ранние проверки заимствованных имён, требовавшие от новичка ещё не изученного чтения;
- вопрос по отрицанию, где два ответа были защищаемы; теперь он указывает конкретное «түгелдер»;
- грамматическое объяснение «Бал татлы», термин сәкен и несколько татарских опечаток.

Это проверка подготовленного содержания, а не утверждение о независимой научной экспертизе всего учебника. Реестр44решений по самому источнику находится в `docs/02-source-decisions.md`. Сомнительная исходная форма сохраняется в архиве с причиной, а не превращается в произвольно исправленный ключ.

## Воспроизводимые проверки

Из корня репозитория:

```sh
python3 tools/build_indexes.py
python3 tools/validate_content.py
git diff --check
```

Для окончательного результата используется строгий режим без `--partial`. Проверяются:

1. SHA-256 неизменённого извлечения книги;114уникальных узлов и непрерывные границы LF-строк.
2. Порядок и зависимости обоих маршрутов, наличие всех53уроков и навыков, покрытие источника.
3. Полные поля теории, уникальные ID правил/примеров/вопросов, исходные формы в указанных строках.
4. Ключи, варианты, совместимость типа вопроса и проверки; минимум8заданий и2переноса наурок.
5. Отсутствие контрольного источникового примера в обычной практике того же банка; отдельность итоговых строк.
6. Сохранение всех540исходных IDs и написаний; построчные ссылки обеих частей словаря; запрет практики по справочным/архивным записям.
7. Ссылки слов в чтении, допуск словарных подсказок, вопросы и итоговая группа `reading_final`.
8. Совпадение12аудиосценариев с текстовыми чтениями; отсутствие зависимости от несуществующих записей.
9. Полнота указателя145правил, словарные связи курса,34буквы и8обычных несоединяющихся знаков.
10. Существование31ресурса манифеста, размеры и контрольные суммы; отсутствие незавершённых TODO в данных.

Итог строгой проверки после редакционных исправлений: **0ошибок**. Индексы воспроизводятся из тех же данных. Проверка не запускает приложение и не подтверждает будущую браузерную отрисовку, поскольку интерфейс ещё не реализован.

## Границы готовности

Материалы достаточны для реализации описанных уроков, практики, словаря, чтения и локального PWA без самостоятельного изобретения разработчиком учебной последовательности и ключей. Все пользовательские объяснения и постоянные сообщения подготовлены на татарском.

Исторические редкие статьи без надёжного чтения оставлены справочными,38сомнительных пар закрыты архивным решением. Это свойство подготовленного выпуска, а не оставленные разработчику пустые поля для угадывания.

Аудио и самостоятельный корпус рукописей не входят в обязательные материалы. Подборки чтения состоят из коротких предложений учебника и прямо так обозначены; это не полноценная хрестоматия и не обещание свободного чтения любого архива. Для более длинной прозы и разных почерков потребуется следующий учебный уровень.

Рецензия специалиста по старотатарской письменности, пилот с учениками и проверка шрифтов в реализованном интерфейсе не проводились. Перед публичным распространением исходного учебного материала нужно определить основание для его публикации; локальное наличие DOC само по себе этого не устанавливает. Эти границы не мешают завершённой локальной подготовке содержания и технического задания.
