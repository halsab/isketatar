# Словарь: готовые записи, область применения и поиск

## Состав поставки

В `content/lexicon/` находятся:

- `source-thematic.json` — все 257 исходных записей §5.5 с чтением/эквивалентом, пояснениями в скобках и координатами текста;
- `source-historical.json` — все 283 статьи §5.6 с точными исходными определениями и восстановленной структурой всех 257 строк таблицы;
- `lexicon.json` — все 540 записей после татарской редакции и адресного решения об использовании;
- `editorial-decisions.json` — решения по изменённым, неоднозначным и исключённым статьям;
- `search-cases.json` — примеры ожидаемого поведения поиска и его отличия от проверки ответов.

Все исходные IDs сохранены: `lex-55-001`…`lex-55-257` и `lex-56-001`…`lex-56-283`. Удалённых исходных статей нет. При повторе одной леммы сохраняются оба источниковых вхождения и связи между ними. Исходниковые файлы содержат контрольные суммы предоставленного DOC и текстового извлечения.

| Область использования | §5.5 | §5.6 | Всего |
|---|---:|---:|---:|
| `active` — словарь и практика в указанном контексте | 252 | 6 | 258 |
| `reference` — словарь со значением, без автоматического ключа | 0 | 244 | 244 |
| `archive` — редакторский архив | 5 | 33 | 38 |
| **Всего** | **257** | **283** | **540** |

У 263 записей сохранено или обоснованно добавлено татарское чтение. Пять из них относятся к архивным парам §5.5: чтение в книге есть, но соответствующее написание не принято. Поэтому **для активной практики доступны 258 исходниковых записей**, а не 263. Это не число уникальных лемм: повторы связаны отдельно.

277 редких статей не получили выдуманного чтения. Их отсутствие чтения — окончательное свойство этого выпуска словаря, а не пустая задача для разработчика. Из них 244 доступны в справочном режиме, 33 находятся в архиве. В §5.6 источниковая пометка «зи» относится только к одной форме внутри статьи `lex-56-122`; она не становится чтением всей группы.

## Что показывать пользователю

У обычной записи:

1. `display_form` — историческое написание;
2. `reading_tt` — татарское чтение кириллицей, только если оно есть;
3. `meaning_tt` — самостоятельное татарское пояснение;
4. при наличии — связанные формы/другие значения и ссылка на источник;
5. при значимом изменении исходника — объяснение `editorial_notes_tt`.

Заголовки интерфейса: **Язылыш**, **Укылыш**, **Мәгънә**, **Бәйле сүзләр**, **Чыганак**. Для справочной статьи без чтения: **«Мәгънәсе чыганак буенча бирелде. Татарча укылышы күрсәтелмәгән.»** Поле чтения не заменяется арабским произношением, латинской транслитерацией или автоматически прочитанным аудио.

Слова архивного уровня не попадают в обычную выдачу, карточки повторения, тексты как словарные подсказки и варианты ответов. Разработчик не должен «добивать» их догадками, чтобы заполнить все поля. У каждой такой записи уже есть конкретная причина исключения на татарском, исходная форма и исходная ссылка. Архив служит сохранению и проверяемости источника.

В тематическом разделе объяснения написаны заново на современном татарском на основе явно данного книжного эквивалента. Для редких слов отредактированы исходные определения: убраны русские пояснения, исправлены очевидные татарские опечатки, разделены чтение и значение. Это короткий учебный словарь, а не исчерпывающий нормативный словарь всех значений. Религиозные, исторические и оценочные значения сохраняют контекст источника.

## Поля записи

| Поле | Назначение |
|---|---|
| `id` | Неизменяемая адресация из уроков, текстов и прогресса. |
| `source_form` | Буквальная запись из источника; не заменяется исправленной. |
| `display_form` | Подготовленный Unicode-текст для показа. |
| `reading_tt` | Подтверждённое книжное татарское чтение или `null`. |
| `meaning_tt` | Татарское объяснение; у архива оно хранится как документирование отвергнутой пары. |
| `meaning_origin` | Различает авторское пояснение эквивалента и татарскую редакцию исходного определения. |
| `section`, `source` | Раздел, строка `sources/textbook.txt`; при необходимости координаты статьи в таблице. |
| `origin.profile` | Профиль конкретного написания; `loan_original` не означает арабское произношение. |
| `status` | Статус по редакционной политике: `source_checked`, `editorial_checked`, `source_only`, `disputed`. |
| `eligibility` | Явное разрешение показа и практики с причиной на татарском. Это главное поле допуска. |
| `constraints` | Условия использования: контекст для омографии, проверка только чтения, запрет автоматических ключей. |
| `corroboration` | Подтверждение из другого места книги или внешнего источника. |
| `links` | Связи с повтором, другим чтением того же написания или составной формой. |
| `forms` | Разделённые формы статьи; пометка о том, что группировка в источнике не делает их универсальными вариантами ответа. |

Статус `source_checked` означает сверку с данным учебником, а не научную рецензию по всем нормам исторической орфографии. Допуск `active` позволяет использовать конкретную пару для чтения. Для свободного написания слова на арабице отдельное задание по-прежнему задаёт профиль и допустимые формы. Обратная генерация всех написаний из кириллического чтения не следует из этой базы.

## Содержательные решения

Подтверждённые исправления §5.5:

| ID | Было | Показывается | Основание |
|---|---|---|---|
| `lex-55-025` | `قایمت` | `قيامت` | Та же пара «кыямәт» в §5.5.4, строка 1922. |
| `lex-55-028` | `حدا` | `خدا` | §5.2, строки 1659–1660; книга даёт `خدا` / `خداي`. |
| `lex-55-030` | `پیعمبر` | `پيغمبر` | §5.2, строка 1647; также встречается в текстах книги. |
| `lex-55-097` | `خسرت` | `حسرت` | Публикация КФУ: историческое написание и чтение xäsrät приведены вместе. |

У `lex-55-154` оставлено чтение «кеше», а «әдәм, шәхес» отнесены к пояснению. Присутствие этого слова в тематическом разделе заимствований не превращается в утверждение о его происхождении. У `شاکرد` сохранён прямо данный книгой эквивалент «шәкерт» и профиль `book_unspecified`: эта пара служит чтению данного источника, но не эталоном всей персидской орфографии.

В §5.6 исправлено противоречие `lex-56-252`: исходное `نَوبت` → «чырай» заменено в показе на **нәүбәт — чират**. В исследовании «Нур» из фонда КФУ представлены `نوبت`, чтение näübät и современная передача «чираттагы». Исходное «чырай» сохранено в источниковом JSON. Ещё пять чтений перенесены из точно соответствующих пар §5.5: **исем, савап, завык, зар, нисбәт**. Перенос учитывает одинаковые основные буквы, но не создаёт общего правила удаления значимых огласовок из ответов.

Адресные редакторские сокращения не маскируются под весь исходный смысл. Например, у `حضورنده` показан смысл «перед, в присутствии», сформулированный по-татарски, и сохранено ограничение на словоформу; у `ذَات` не перенесено сомнительное утверждение о множественном числе; у `هنوز` оставлено «әле дә, һаман да». В этих справочных статьях нет автоматического ключа.

Пять исключённых тематических пар: `كاعد — кәгазь`, `عزل — газәл`, `خيران — хәйран`, `بحـت — бәхет`, `عاقل — гакыл`. Они имеют конкретные буквенные или лексические противоречия. Для 33 исключённых редких статей решения приведены в `eligibility.reason_tt` и реестре: недостаточно установить корректную форму/соответствие, поэтому именно исходная пара исключена из показа. Это окончательное решение для текущего комплекта, без неопределённых TODO.

Внешние материалы:

- [Исследование языка газеты «Нур», фонд КФУ](https://dspace.kpfu.ru/xmlui/bitstream/handle/net/91929/070423_d.pdf?isAllowed=y&sequence=1): PDF с. 76 — `حسرت` / xäsrät, «Нур», 1905, №9; PDF с. 74 — `نوبت` / näübät, «Нур», 1906, №41. Использованы конкретные сопоставления написания и чтения.

Индивидуальные статьи через интерактивный поиск в этой работе не получены; справочная страница не используется как доказательство исправления слов.
- [«Гакыйль» и «гакыл» в электронной передаче словаря Хәмзина, Мәхмүтова, Сәйфуллина](https://www.garap-farsy.narod.ru/gak.htm): показывает, почему нельзя отождествлять эти кириллические слова. Арабское написание не было надёжно извлечено, поэтому эта страница не стала основанием для автоматического исправления `عاقل`.

## Поиск и проверка ответов — разные операции

**Поиск возвращает кандидатов. Проверка ответа принимает только явно разрешённые значения конкретного задания.** Совпадение поисковых ключей не доказывает одинакового чтения, смысла или исторической нормы.

Уровни поиска:

1. Точное совпадение с `display_form`, чтением или явно связанной формой. Кириллический регистр и внешние пробелы при поиске несущественны.
2. Совместимые позиционные Unicode-формы и сузу билгесе `ـ` приводятся к поисковому ключу. Исходный текст сохраняется.
3. Для дополнительной арабской выдачи допускается ключ без необязательных огласовок, но результаты показываются с полным написанием. Это помогает найти `مُهِم` по `مهم`.
4. Похожесть `ي/ی/ى`, `ك/ک` может использоваться только как дополнительная явно расширенная выдача. Она не меняет записи и не расширяет ответы. Знаки татарских гласных `ۈ`, `ۇ`, `وُ`, `و` не превращаются безусловно в один учебный знак.
5. Поиск по `meaning_tt` предназначен для нахождения понятия, а не для автоматической генерации транслитерации. Нечёткая выдача не изменяет правильность ответа.
6. Архив по умолчанию исключён на всех уровнях. Если активного совпадения нет, интерфейс сообщает об отсутствии слова и не предлагает сомнительную архивную пару как правильную.

**Обязательный случай `عالم`:** выдача сохраняет две отдельные записи — `lex-55-046` «галим» и `lex-55-158` «галәм». В выдаче видны оба чтения и разные объяснения. В свободном задании без контекста нельзя считать одно из этих чтений ошибкой. Если задача проверяет «галим», она показывает смысл или контекст, указывающий на человека науки.

**Повторы:** `طرف`, `اِعلان`, `حرمت`, `قيامت`, `مهم/مُهِم` связаны с повторными источниковыми вхождениями. Интерфейс может группировать их в одну карточку с несколькими источниками, но не должен терять IDs и происхождение. Разные значения `عالم` таким способом не схлопываются.

**Составные статьи:** `حال، حالات` включает отдельную форму и множественное число, а не два допустимых ответа на любой вопрос. `ذَا، ذِى` тоже нельзя выдавать как свободно взаимозаменяемые варианты. Поле `forms.relationship` прямо запрещает такое обобщение.

## Достаточность и проверки

Материал готов для реализации словарного раздела в предусмотренных границах: 502 записи допускают пользовательский показ, 258 — практику при соблюдении ограничений. У каждой из 540 записей есть источник, татарское пояснение, статус и окончательное решение о показе. Нет пропавших исходных IDs и оставленных «потом проверить» вместо решения.

Проверки комплекта: количество записей и уникальность IDs; полное совпадение исходных форм с источниковыми JSON; существование всех связанных IDs; непустое татарское значение; обязательное чтение у `active`; отсутствие допуска практики у `reference/archive`; существование адресного решения для каждого архива; отсутствие известных русских вставок в `meaning_tt`; совпадение строк источника для всех редких статей. Проверка JSON не выдаётся за независимую лингвистическую экспертизу: её предмет — целостность материалов и соблюдение указанной редакционной политики.

## Лексика уроков

`course-vocabulary.json` добавляет 282 адресованных словарных вхождения из примеров курса. Это вхождения, включая словосочетания и повторные формы, а не 282 уникальные леммы. Каждое связано с уроком, конкретным примером, профилем, источником и вопросами; точные подтверждённые совпадения связаны с основным словарём. Буквенные карточки B01–B06 и примеры без подтверждённого чтения сюда не переносятся.

`release: with_lesson` позволяет показать слово вместе с уроком. `after_linked_question` сохраняет контрольный материал закрытым до соответствующего задания. Это ограничивает преждевременное раскрытие внутри курса, а не гарантирует, что ученик никогда не видел такого слова вне приложения. При поиске одинаковые вхождения объединяются для показа, но источники и профили остаются видимыми; нельзя считать каждое вхождение отдельной леммой. Указатель собирается из готовых примеров инструментом `tools/build_indexes.py`.
