# Реализация курса

Начало: 12 сентября 2026 года. Основание — [D0–D12](../production/11-development-roadmap.md). Новое поручение владельца разрешает разработку и локальные коммиты; прежнее ограничение «только документация» относится к завершённому этапу проектирования. Push и публичный релиз не выполняются.

Каждый этап и выделенный подэтап выполняется последовательно: границы → необходимые проверки → реализация → независимое ревью с чистым контекстом → исправления → локальный коммит. Тесты прежде реализации применяются к предметным правилам, транзакциям и отказам; для вёрстки используются проверки браузером. Ревьювер читает спецификацию и diff самостоятельно, не получает объяснений автора реализации.

## D0: исходная база

Базовый commit `0f02e19`, content version `2026.09.11.1`. [baseline.json](baseline.json) фиксирует исходный manifest, обязательные ресурсы и снимок текста учебника. Все 31 обязательный JSON проверены по SHA-256 и размеру. Объём обязательного пакета — 2 131 151 байт. Записанного аудио нет; незаписанное аудио не выводится как доступный control.

`python3 tools/validate_content.py`: 0 ошибок, 53 урока, 145 правил, 361 пример, 436 вопросов курса, 540 исходных словарных записей, 12 текстов. `python3 tools/validate_production_docs.py`: pass, 0 ошибок. Это проверка исходников и спецификаций, не приложения.

Git remote: `https://github.com/halsab/isketatar.git`. Технический Pages owner — `halsab`, base path — `/isketatar/`. Публичное имя и контакт проверяются перед выпуском по [условиям](release-conditions.md). Существующие `.DS_Store` не являются результатом разработки и не включаются в коммиты.

UI-copy: 194 исходные строки + 72 добавления / 8 замен = 266 строк после переноса. Подготовленный план остаётся источником переноса, а не доказательством контекстной вычитки.

Агрегатный `corpus_sha256`: SHA-256 от UTF-8 сериализации массива `files` через `json.dumps(files, ensure_ascii=False, sort_keys=True, separators=(',', ':'))`, без завершающего LF. Пути отсортированы; каждый объект содержит path/sha256/bytes.

Независимое ревью D0: воспроизведены валидаторы и все 33 hashes; исправлена привязка S09–S19 к экранам, уточнены алгоритм hash и объём татарской вычитки. Инженерная приёмка D0 завершена; внешние условия остаются в отдельном реестре.


## D1: основа и сборка

Закреплены Node 24.21.0 LTS, npm 11.9.0 и точные версии зависимостей в package.json/lockfile. Добавлены React/Vite/TypeScript strict + noUncheckedIndexedAccess, HashRouter, base `/isketatar/`, татарские noscript/recovery, строгая production CSP и проверки границ модулей/состава dist. CI выполняет проверки и сборку без deploy; официальные actions проверены по Git refs и закреплены полными SHA. PR имеет только contents:read.

Проверки на Node 24.21.0: оба исходных валидатора, module boundaries, TypeScript, 7 unit assertions, production build; initial JS 82.96 kB gzip. Во встроенном Chromium открыта и перезагружена прямая `/isketatar/#/about`; закреплённый Playwright smoke проверяет ссылку/reload/переход домой. `npm audit --omit=dev --audit-level=high`: 0 известных уязвимостей. Shell этого этапа не является завершённым курсом; шрифты/экраны/прогресс/worker добавляются последовательно.

Независимое ревью D1: исправлена блокировка CSS Vite в dev, повторно проверены styles/console, production CSP, bootstrap/recovery и hash-навигация. Открытых замечаний нет; этап допущен к локальному коммиту.


## D2.1: типизированный каталог и ревизии

Границы: domain/content, data/content, сборочные инструменты/JSON Schema, runtime-каталог строк. Источники проверяются по исходным hashes и отдельной source schema; runtime имеет закрытые схемы и явную проекцию. Ajv standalone генерируется при сборке, без compile/eval в браузере. 266 татарских строк перенесены в src/ui/tt.json; внешняя вычитка остаётся в реестре.

Каталог разделён на core, восемь модулей, readings, assessments, dictionary и references. Репозиторий загружает нужный раздел, проверяя MIME, размер потока, SHA-256, UTF-8 и schema; неуспешный запрос можно повторить. Archive исключён до пользовательского каталога. Стабильные IDs, null readings и исходная графика сохранены; координаты слов последовательные UTF-16. Grading revision учитывает разрешённый читаемый контекст, но не explanation. Таблица разрешённых арабских presentation forms зафиксирована явно и используется только для ключей знакомства/поиска.

Обнаружено исходное различие source_sections у 11 уроков; адресное уточнение в 02 сохраняет объединение ссылок программы и полного урока. Исторические формы и ключи не менялись. Сборочный release manifest содержит версии, политики, revisions и hashes всех ресурсов из allowlist; собственный hash не включает. Время берётся из SOURCE_DATE_EPOCH или commit timestamp, ID включает время и bytes; неизменяемые URL выпуска подключаются в D8.

TDD: каталоговый тест сначала завершился ошибкой отсутствующего адаптера, затем стал проходить на полном корпусе. Проверены количества, A02, word ranges/READ-03, null/архив, LC-28, schema rejection и повреждённая загрузка. Учебный reducer, оценки и остальные LC относятся к следующему D2.2; сохранённой истории пока нет.

По независимому ревью исправлены ключи знакомства с отдельными словами H03, включение разметки слов в ревизию строки, проверка обеих границ графемы и явная проекция вложенных объектов без редакторских полей. Помимо закрытой JSON Schema проверяются допустимые ключи ответов, сложность, уникальность IDs, порядок координат и внутренние ссылки, включая принадлежность каждого урока модулю. Несовместимая схема/политика отличается от повреждённых bytes. Зафиксированы регрессионные примеры: 36 unit tests, TypeScript, границы модулей, исходные валидаторы и production build проходят.
