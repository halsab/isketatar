## D9.3b — холодный запуск

Runtime запускается параллельно renderer через общий Promise; начальное событие установки перехватывается до обоих. HTML hints включают обязательный JS/CSS, а bootstrap загружает выбранную страницу и её отдельный standalone validator. Все ленивые страницы начальной оболочки входят в shell cache и размерный бюджет. Схемы не ослаблены; Ajv использует общие определения и циклы для required/enum.

Ранняя регистрация worker делится с runtime. Предварительный запрос manifest не пишет CacheStorage/IDB и не принимает выпуск: worker хранит один ограниченный результат обычного fetchManifest с проверкой размера, MIME, URL, JSON и структуры. Страница получает результат по созданному ею MessagePort и повторяет parseRelease, версии, policies, content-index и принадлежность собственному immutable URL. Клиент не передаёт worker готовый manifest. Если подтверждение новой команды ещё не пришло, bootstrap сразу использует обычный fetch; отказ после подтверждения также включает обычный запрос. Повторный старт после отказа активации заново регистрирует transport; поздний отказ старого waiter не сбрасывает новый Promise.

Initialize возвращает проверенную роль выпуска до автоматического сохранения shell. Запись shell остаётся в сериализованной очереди worker перед обновлением/удалением и удерживается event.waitUntil. Ошибка фоновой записи видна в состоянии PWA и не закрывает уже работающую онлайн-страницу; полный курс не становится ready. Ресурсы сохраняются порциями по четыре: отказ ожидает уже начатые записи и не запускает следующую порцию.

Первый свободный поиск не скачивает vocabulary; доступ к учебным вхождениям по-прежнему определяется экспозициями/ответами. Загрузчик сохраняет прежнее агрегирующее имя dictionary.json и отдельный адаптер для retained выпусков с единым файлом. Оба новых ресурса обязательны в manifest и полном офлайн-пакете. Форма поиска остаётся смонтированной при догрузке: ввод и фокус сохраняются, устаревшие ответы игнорируются, индекс обновляется после загрузки. Счётчик появляется после данных; сами группы остаются за font/Disclosure gates. Заголовок урока берётся из проверенного core до загрузки документа; прежняя граница SessionContent сохранена.
