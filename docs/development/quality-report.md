# Приёмка реализации

Отчёт отделяет автоматизированную инженерную проверку от внешней приёмки. Конкретные builds, команды и итоги этапов записываются ниже. Проверки после изменения затронутого кода повторяются; старый отчёт не разрешает публикацию нового SHA.

## D9.1 — движки и полный корпус

Playwright1.63.0: Chromium153.0.8010.12, Firefox155.0, WebKit26.6; macOS на arm64, Node24.21.0. WebKit — тестовый движок, не физический iPhone и не установленный Safari. Все общие сценарии выполняются в каждом движке, retries=0. Шесть сценариев прямой инъекции отказа в worker выполняются только в Chromium: API [serviceWorkers](https://playwright.dev/docs/api/class-browsercontext#browser-context-service-workers) отсутствует в других движках. Полный корпус выполняется один раз в Chromium; основные учебные механики и все четыре answer controls проверяются во всех трёх.

| Область | Исполняемые сценарии |
|---|---|
| 53 урока, 494 вопроса, обе траектории | full-course, course, lesson, assessment, reading-practice |
| Draft, IME, writer, помощь, память, импорт/reset | controls, progress, runtime, lesson, dictionary, settings |
| Чтение, словарь, справочник, источники, повторение | reader, catalogs, dictionary, review |
| Immutable shell, холодный старт, вытеснение и pinned release | release, offline, retained, bootstrap |
| Два выпуска, согласование окон, crash/recovery, удаление пакета | update, remove-offline |
| Установка и ручные инструкции | install |
| Шрифты, направления, reflow и загрузочный отказ | typography, controls, course |

Полный проход читает реальные страницы всех уроков, отправляет авторские ключи всех вопросов, проверяет feedback/acknowledgement и20 итоговых заданий с закрытым до submit разбором. Он подтверждает проводку UI и сохранение494 Attempts/65 завершённых Session после смены пути и reload. Лингвистическая правильность ключей этим способом не подтверждается.

Офлайн проверяется отключением HTTP у изолированного тестового сервера: каждый запрос, в том числе от worker, завершается обрывом соединения, готовый ответ не подменяется фикстурой. После смены режима повторно проверяется и ответ уже начавшегося чтения файла. Первоначальный прогон обнаружил ограничения Playwright setOffline: Firefox отвергает fetch с cache=no-store, WebKit — navigation даже с активным worker. Это воспроизведено отдельно минимальным worker, всегда возвращающим синтетический HTML, без кода курса. При обрыве HTTP тот же worker обслуживает оба запроса. Серверный метод проверяет отсутствие сети, но не системный индикатор navigator.onLine или авиарежим устройства.

Итог D9.1:230 unit-тестов; общий прогон трёх движков дал245 успешных,14 пропущенных и2 сбоя. После исправления очереди записи и возврата фокуса повторены затронутые сценарии:111 успешных,8 пропущенных; единственный сбой нового теста полного корпуса был ошибкой относительного селектора. После исправления селектора отдельный полный проход494 вопросов успешен за3 минуты. Это совокупность общего и адресных повторов, а не заявление о едином полном прогоне после последней правки. Build `1.0.0-d25dc58ace814f7e`,61 ресурс,3 892 852байта. Независимое ревью с чистым контекстом подтвердило исправления очереди, debounce, WebKit focus и отсутствие сетевой утечки в outage fixture.

JSON-отчёт каждого общего прогона записывается в test-results/results.json; trace при сбое остаётся рядом. Чужие пользовательские данные не используются.

## D9.2 — доступность, reflow и шрифты

`@axe-core/playwright`4.13.0 выполняет56 сканирований production DOM:20 семей/вариантов страниц в обеих темах, вопрос/ошибка ввода/feedback, узкая и широкая панель, reset/import error, diagnostic/final navigation/confirmation/result, ошибки content/font/storage. Включены WCAG2/2.1/2.2 A/AA и best-practice rules, без исключённых selectors/rules. Перед анализом ожидаются данные, шрифты и завершение конечных анимаций. Полные результаты и снимки неоднозначных состояний прикладываются к Playwright report. Метод основан на [официальной интеграции axe](https://playwright.dev/docs/accessibility-testing).

Итог:0 violations. Пять incomplete color-contrast относятся к пересекающимся bounding boxes многострочных ссылок/абзацев внутри native dialog и сообщения шрифта. Состояния просмотрены: видимого наложения текста нет; используются проверенные пары ink/surface, primary/surface и text-muted/canvas. Это разбор конкретных неоднозначностей, не отключение правила. Все122 пары канонических цветов пересчитаны штатным валидатором.

Reflow:72 сочетания9 страниц ×320/360/640/1120px ×100/200% корневого текста; пользовательский текст24px, арабица28/32/40/48px распределена по ширинам, светлая/тёмная темы — по размеру текста. Увеличены применимые межбуквенные/межсловные/абзацные интервалы; арабица не разряжается. После layout проверяются ширина документа и геометрия элементов основного содержимого. Урок, читалка и настройки просмотрены на320px с крупным текстом и forced-colors. Reduced motion включён; полный физический400% zoom и AT остаются ниже.

Исправлены: уровень заголовка модуля, отсутствие заголовка при ошибке загрузки страницы, промежуточный контраст при смене темы, перенос длинных h2/h3/определений, возврат pointer focus после подтверждения и переход фокуса при смене модальности. Боковая панель сохраняет нативный немодальный dialog: override role=region запрещён [HTML/ARIA](https://www.w3.org/TR/html-aria/#el-dialog). При сужении становится модальной в том же DOM. Независимое ревью обнаружило подавление touch click в WebKit при отмене pointerdown; TT-вставка/undo теперь сохраняют focus явно и отменяют только mousedown. Самостоятельные probes и hasTouch regression прошли в трёх движках, включая WebKit mobile emulation.

Повторная подготовка WOFF2 дала те же SHA-256:1200 уникальных арабских runs без изменения shaping,73 кириллические кодовые точки без пропусков; см. font-build.json. Полный check230 unit-тестов. Общий адресный прогон104 passed/30 skipped выявил единственный reflow defect; после исправления все16 Chromium accessibility-тестов (56 axe scans и72 reflow cases) прошли за30 секунд. Последняя CSS-правка независимо допущена. Build `1.0.0-d440b135b6d314f8`,61 ресурс,3 893 901байт. Синтетический IME и эмуляция touch не объявляются проверкой системной клавиатуры.
