# Визуальная реализация

Канонический источник — DESIGN.md и 04/07. Визуальный ориентир показывает учебную главу: шапку, открытый документ, пример, поле с татарскими клавишами и соседний контекст. Его иллюстративные формулировки не заменяют подготовленный корпус.

Инвентарь D4: Inter 400/600; Noto Naskh Arabic Regular; точные 23 цвета каждой темы; размеры из токенов; Button/IconButton, нативные radio/checkbox, TextAnswer с шестью клавишами и отдельным +, постоянные статусы, именованные диалог/панель, source card, таблица. Связные арабские слова остаются текстом; иллюстраций и растрового текста в продукте нет.

Шапка и пять пунктов следуют 05: Дәресләр, Кабатлау, Уку, Сүзлек, Белешмә; логотип ведёт домой, настройки отдельно. Это сознательное уточнение иллюстративного ориентира по каноническому маршрутизатору. Основное действие, подписи и учебный текст берутся из runtime-каталога и корпуса. Обложки, показатели без истории и декоративные бейджи не требуются для учебного сценария.

Контейнер: 1280px; документ до 680px, панель 320px, зазор 24px. Теория открытая, рамка используется у примера/задания/поля. Цветовая основа тёплая #F7F4ED, без фоновых эффектов. Контрольные точки визуального сравнения: палитра, шрифты/вес, геометрия документа/панели, 48px controls, отсутствие обрезанных арабских marks, адаптивное размещение навигации.

Полная проверка соответствия и сценариев фиксируется по мере подключения экранов; матрица шрифтов D4.1 не выдаётся за готовый учебный экран.

## Сверка D4.2

Обзор компонентов открыт во встроенном браузере, снимки Chromium проверены на 1440×1080, 390×844 и 320px с корневым текстом200%. Сопоставлены шесть пунктов: точные тёплый фон/поверхность/зелёный, Inter/Noto и настоящий вес, ширина документа680px и отступы, рамки примера/поля без декоративных эффектов, 48px ввод/клавиши, навигация и модальная панель на телефоне. Арабские строки остаются настоящим текстом и не получают цвет результата.

Исправлены вертикальное разбиение логотипа при200%, неудачный перенос последней буквы нижнего пункта и скриншот промежуточного кадра диалога: финальный снимок снимается при opacity1. Нижние пункты делят ширину с учётом длины татарской подписи, каждый имеет доступную цель минимум44px. По сравнению с ориентиром названия навигации и теории взяты из канонических05/UI-copy; величины шрифтов/документа — из04, иллюстративный масштаб картинки не заменяет их. Соседнее оглавление появляется по запросу, как требуетS04. Полный корпус подключается далее, поэтому этот обзор не является снимком завершённого урока.

Добавлены две необходимые строки ввода: `keyboard.finish_composition`, `keyboard.answer_limit`. Теперь runtime-каталог содержит268 строк; обе передаются на внешнюю контекстную вычитку вместе с исходными266. Сценарий компонентов: выделение→вставка→undo, запрет вмешательства в composition, Enter без двойной отправки, открытие источника→смена модальности с сохранением фокуса/прокрутки→закрытие.
