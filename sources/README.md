# Источники и воспроизводимость

Основной источник предоставлен пользователем: «Иске татар имля 3-20.11.19.doc».

- Автор на титуле: Әхмәд хәзрәт Сабыр; библиографическая запись: Сабиров А.
- Название: «Иске татар имлясы буенча дәреслек».
- Издание: третье, Казань, «Иман», 2020, 88 с.
- SHA-256 исходного DOC: `9bf75da660303f3158b63ac5eb1f25fa67226480236632ffde61df212c636015`.
- Извлечение текста: `textbook.txt`, 3218 строк, SHA-256 `a3474bb9f43f2af3db5ee5711a4cb2b20fdd51eead5a0921569f8e847ac19efc`.

Извлечённый текст сохраняется неизменным для адресации источника. Управляющие символы таблиц, Presentation Forms, арабские/персидские варианты кода и типографические пробелы в нём являются частью исходного извлечения. Их нельзя напрямую переносить в пользовательский интерфейс. Для неоднозначных таблиц применяется сверка с DOCX/PDF, полученными из того же файла.

Ссылки на источник в содержимом задаются разделом и строками `textbook.txt`. При совпадении номеров подразделов дополнительно используется название: в главе 4 есть повторная нумерация.

Это рабочий корпус для подготовки материалов. Наличие файла у пользователя и локальные коммиты не устанавливают лицензию на публичное воспроизведение всей книги. Перед публикацией отдельно определяется разрешённый объём использования исходного издания. Подготовка курса и локальная работа продолжаются без публикации.
