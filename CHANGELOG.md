# Внутренний журнал изменений

## 1.0.0 — кандидат, не опубликован

Реализован первый полный текстовый курс: 53 урока, диагностика18 и итог20 вопросов, чтение12 текстов, словарь502 видимых записей, повторение, локальный прогресс, перенос резервной копии и PWA. 494 вопроса включают436 заданий уроков,18 диагностических,20 итоговых и20 обычных вопросов чтения; четыре итоговых RQ уже входят в20 итоговых и повторно не считаются. [Татарские заметки](RELEASE_NOTES.tt.md) описывают изменения для ученика.

| Контракт | Значение кандидата | Изменение / миграция |
|---|---|---|
| app_version | 1.0.0 | Первый выпуск приложения |
| content_version | 2026.09.11.1 | Исходный корпус из content/manifest.json; release manifest сохраняет revisions всех вопросов |
| content_schema | 1 | Строгая проекция исходного корпуса |
| progress_schema / db_version | 1 / 1 | Создание новой БД; опубликованных исторических схем нет |
| min_reader_version | 1.0.0 | Неизвестные версии/политики не принимаются |
| grading / normalization | grading/1 / tt-reading/1 | Канонизация ключа и проверка ответа раздельны с поиском |
| mastery / diagnostic / final | lesson-mastery/1 / diagnostic/1 / final/1 | Сохранены независимость ответа и замороженный план |
| review / exposure | review/1 / exposure/1 | SRS и монотонная помощь |
| release_access / search / import | release-access/1 / dictionary-search/1 / progress-import/1 | Доступ, поиск и атомарный перенос |

Номер приложения не определяет физическую миграцию. В v1 поддерживается schema1; обещаний преобразования из несуществующей старой схемы нет. release_id, manifest/inventory/source/product SHA и lockfile связываются в provenance каждого кандидата. Для обновления сохраняются текущий и предыдущий immutable-пакеты; accepted release меняется только через согласование вкладок. Возврат сайта не является откатом IndexedDB или принудительным понижением установленного приложения.

CI проверяет единственную сборку и публикует её только после одобрения внешних условий. После HTTP/browser smoke сохраняется last-good; предусмотрен ручной workflow возврата известного выпуска. Публикация в ходе разработки не выполнялась. [Журнал шагов](docs/development/implementation.md), [качество](docs/development/quality-report.md), [условия выпуска](docs/development/release-conditions.md).

Для следующей версии добавить раздел с app/content/schema/policies до и после, IDs изменённых материалов, изменением grading_revision, поведением старых результатов/SRS/черновиков, поддерживаемыми миграциями и доказательствами upgrade/recovery. Исправление одного explanation без изменения проверяемого смысла не сбрасывает обучение. Порядок изменений — в [инструкции сопровождения](docs/development/maintenance.md).
